# BGOBS 0.3.26

- Adds the optional **Studio calibrated (experimental, BMv2)** matting engine.
  Select it in the **Matting engine** menu, capture the empty camera background,
  then return to frame. This is distinct from the **Studio** appearance preset.
- Includes the reconstructed foreground and paired alpha/frame path for both
  RVM and BMv2, plus a bounded inference queue to prevent delay from growing
  without bound.
- Publishes Linux x86_64 and Windows x64 packages from this same version. The
  Windows package includes its DirectML runtime; automatic and CPU fallback
  modes remain available.

The calibrated-studio engine is experimental. Capture a new reference after
changing the camera, crop, rotation, or resolution. Its speed and quality vary
by device; check the measured delay in OBS before relying on it.

These packages have passed the automated build and packaging checks. Windows
hardware behavior still needs confirmation on a real Windows OBS setup; this
release makes no claim that a Windows hardware smoke test has been completed.
